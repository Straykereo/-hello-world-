# Лог промптов и ответов (AI Assistance Log)

## 1. Проектирование архитектуры и моделей данных
**Промпт:**
> Спроектируй на Java 21 структуру классов для генератора уровней игры «Слова из слова». На вход подаются словарь `dictionary`, список главных слов `mainWords` и объект `config` (`minSubWordLength`, `minWordsToPass`, `difficultyThresholds`). На выход должен формироваться JSON со списком `levels` (`id`, `mainWord`, `difficulty`, `minWordsToPass`, `subWords` с полями `text` и `hint`), при этом `config` не должен попадать в выходной JSON. Используй `record`, `enum` и библиотеку Gson.

**Результат:**
- Созданы неизменяемые модели `LevelInput` (с вложенными `Config` и `DifficultyThresholds` и валидацией порогов), `LevelOutput`, `Level`, `SubWord` и перечисление `Difficulty` (`EASY`, `MEDIUM`, `HARD`).
- Настроен `JsonIO` на базе `GsonBuilder().setPrettyPrinting()` с чтением и записью в кодировке UTF-8.

---

## 2. Алгоритм подбора подслов и нормализация
**Промпт:**
> Напиши класс `LevelGenerator`, который для каждого главного слова из `mainWords` находит подходящие подслова из словаря. Учти правила: сравнение без учёта регистра, замена `Ё` на `Е`, фильтрация слов короче `minSubWordLength`, исключение самого главного слова, запрет дубликатов внутри уровня и точный учёт кратности каждой буквы. Уровень создаётся только если найдено не меньше `minWordsToPass` подслов.

**Результат:**
- Реализована нормализация строк через `toUpperCase(Locale.ROOT).replace('Ё', 'Е')`.
- Написаны методы `letterCounts` и `canBuild` для подсчёта частот символов и проверки возможности составить подслово без превышения кратности букв, а также `Set<String>` для отсеивания дубликатов.

## 4. Автоматическое тестирование и проверка производительности
**Промпт:**
> Напиши класс `SelfTest` без сторонних фреймворков, который проверяет все граничные случаи из ТЗ: повторяющиеся буквы, превышение кратности букв, наличие главного слова в словаре, дубликаты в словаре, короткие слова, разный регистр и букву `Ё`, отсутствие подходящих подслов, точное совпадение с `minWordsToPass`, скорость работы на словаре из 10 000 слов и отсутствие `config` в итоговом JSON.

**Результат:**
- Создан `SelfTest.java` с 10 тестовыми сценариями, замером времени выполнения на большом словаре и выводом статистики `Passed / Failed`.
